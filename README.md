# Ufaj, ale sprawdzaj: jak projektować interakcje z AI

Prezentacja Kaliny Tyrkiel-Szymańskiej na **UX speak in 2026** (27 października 2026, Gdynia).

Treść oparta na wystąpieniu z CAKE conf 2026, przetłumaczona na polski i ostylowana według identyfikacji UX speak in (granat + cyan).

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

Nawigacja: strzałki, spacja lub klik. Przyciski `←` / `→` w stopce slajdu.
